01. À propos

Étudiant à Epitech Paris, j'aime transformer des idées en produits concrets. Côté web, je travaille avec React, Tailwind CSS et Supabase (PostgreSQL) ; côté systèmes, je code en C sous Unix. Je m'intéresse aussi à la cybersécurité.
